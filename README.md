# CircuitSurvival V2

Minecraft Paper 1.20.4 向け工業化・自動化プラグイン

Slimefunライクな多層進行システム。中間素材による段階的なクラフティング進行、EN（エネルギー）概念、
多数の自動化機械、化学処理、物流ネットワークを提供します。

## 主な機能

- **60種以上の機械** - 粉砕・圧縮・精錬・クラフト・発電・化学処理
- **多層進行** - Tier 1-5 の中間素材チェーン（回路基板→演算処理→ENコア→超硬合金）
- **ENシステム** - 発電機・蓄電機・送電ワイヤーによるエネルギー網
- **自動化** - RS信号＋ホッパー＋パイプで全機械の完全自動化が可能
- **化学処理 (Phase 5)** - 原油採掘→蒸留→化学反応でプラスチック・硫酸等を生成
- **高度冶金 (Phase 6)** - 真空溶解炉・高圧プレス機による超硬合金・工業用ダイヤ

## クイックスタート

1. `CircuitSurvivalV2-2.0.0.jar` をサーバーの `plugins/` に配置
2. サーバー起動後、`/cs guide` でガイドブックを入手
3. 初心者ガイドに従って粉砕機・圧縮機・自動精錬炉を作成

## ビルド

```bash
# JDK 17+ と Maven が必要
mvn package -DskipTests
# → target/CircuitSurvivalV2-2.0.0.jar
```
